title: "26. Remove Duplicates from Sorted Array"
tags: [leetcode]
---

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums)
    {
        int cnt = 1;
        for (int i = 1; i < nums.size(); ++i)
        {
            if (nums[i - 1] != nums[i])
            {
                nums[cnt++] = nums[i];
            }
        }
        return cnt;
    }
};
```

- T: $O(N)$
- S: $O(1)$
