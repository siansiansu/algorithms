title: "122. Best Time to Buy and Sell Stock II"
tags: [leetcode]
---

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices)
    {
        int maxProfit = 0;
        for (int i = 1; i < prices.size(); ++i)
        {
            if (prices[i] > prices[i - 1])
            {
                maxProfit += prices[i] - prices[i - 1];
            }
        }
        return maxProfit;
    }
};
```

- T: $O(N)$
- S: $O(1)$
